# 📚 Library Management System (C++)

## 📖 Project Overview

The **Library Management System** is a console-based application developed using **C++** and **Object-Oriented Programming (OOP)** concepts.

This project helps manage different library items such as **Books, DVDs, and Magazines**. Users can add new items, display all records, search for a specific item, check out library items, and return borrowed items.

The project demonstrates the implementation of major **Object-Oriented Programming concepts** including **Class & Object, Encapsulation, Inheritance, Abstraction, Polymorphism, Exception Handling, and Dynamic Memory Allocation.**
